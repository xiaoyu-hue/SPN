# 你的技能名

> 一句话：**这个技能解决什么问题、它存在的理由。**
> 写不出来，说明这个技能还没想清楚——不要为了凑数而建。

## 什么时候该用

列**触发信号**，而不是功能列表。3–5 条足够：

- 用户说了什么、做了什么时该用
- 反过来，什么情况下**不该**用（边界）

## 怎么做

分步骤，每步都要可执行。步骤里如果包含命令，写成能直接复制的样子。

### 1. 【第一步】
### 2. 【第二步】

## 输出格式

给出明确的输出模板。AI 最容易犯的错是输出风格每次都不一样，模板能固定它。

```
【字段】：【内容】
```

## 禁止 / 常见错误

这一节往往比正面指令更有效——它防的是已知的失败方式：

- 禁止【具体行为】：因为【会出什么事】
- 没有做到【X】时，不许声称【Y】

## 边界

- 本技能不覆盖什么
- 什么情况下应该建议用户去找别的方案 / 专业人士
